# Brainsh Editor 1.0

Редактор кода для Android с запуском программ на языке
[Brainsh](https://github.com/Facts566/Brainsh).

## Что умеет

* редактор с подсветкой синтаксиса, номерами строк, кареткой, выделением, undo/redo;
* экранная клавиатура со всеми символами Brainsh — на телефоне системной клавиатуры
  этих символов просто нет;
* запуск программы на отдельном потоке: интерфейс не подвисает, есть Stop;
* защита от бесконечных циклов: лимит шагов, его можно менять в меню;
* ввод данных для команды `,` прямо в консоли;
* файлы скриптов во внутренней памяти, подключение через `%include`, автосохранение;
* встроенные примеры, включая `math.bsh` с макросами из `lib.bsh`.

## Установка

Скачайте `BrainshEditor-1.0.apk` и откройте его на телефоне.
Если система спросит разрешение — включите
**Настройки → Приложения → Специальный доступ → Установка неизвестных приложений**
для того приложения, из которого открывается файл.

Требуется Android 5.1 (API 22) и выше, архитектура armeabi-v7a.

## Первое знакомство

При запуске открывается `hello.bsh`:

```
:72. { H }
>:101. { e }
...
```

Нажмите **Run** — в консоли появится `Hello, world!`.
Дальше откройте **Menu → Examples** и попробуйте `digits.bsh` или `math.bsh`.

## Известные ограничения

* APK собран под архитектуру armeabi-v7a; 64-битная сборка для Google Play — в планах;
* сборка подписана отладочным ключом, для публикации в Google Play нужен свой;
* язык Brainfuck-подобный, реальные программы пишутся в комментариях `{ ... }`.

Исходный код открыт, интерпретатор проверен 53 дифф-тестами против
референсной реализации — вывод совпадает побайтово.
