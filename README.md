# Brainsh Editor

Редактор кода для Android: пишете программу на языке
[Brainsh](https://github.com/Facts566/Brainsh), жмёте **Run** — программа выполняется
прямо на устройстве, вывод идёт в консоль.

Unity 2022.3, UGUI, без TextMeshPro и внешних пакетов.

## Возможности

* редактор кода с подсветкой синтаксиса, номерами строк, кареткой, выделением и историей;
* экранная клавиатура со всеми символами Brainsh (в настольной сборке скрыта);
* запуск программы на отдельном потоке: лимит шагов, кнопка Stop, ввод данных для `,`;
* файлы скриптов во внутренней памяти приложения, `%include` между ними, автосохранение;
* встроенные примеры, меню, настройка размера шрифта и лимита шагов.

## Сборка

```bash
# Android APK
Unity -batchmode -quit -projectPath . -executeMethod AppBuildTool.BuildAndroid \
      -logFile /tmp/brainsh-android.log

# Linux-игра (удобно проверять интерфейс)
Unity -batchmode -quit -projectPath . -executeMethod AppBuildTool.BuildLinux \
      -logFile /tmp/brainsh-linux.log
```

## Тесты

Ядро языка проверяется дифф-тестами против референсного интерпретатора на C++:
та же программа запускается обоими, вывод сравнивается побайтово.

```bash
cd Tools/BrainshTests && ./run.sh
```

Каждый процесс референса убивается через 10 секунд, наша машина работает с лимитом
шагов — тесты не могут зависнуть и нагрузить компьютер.

## Структура

```
Assets/Scripts/Brainsh/   язык: компилятор и виртуальная машина (чистый C#)
Assets/Scripts/App/       приложение: редактор, клавиатура, консоль, запуск, файлы
Assets/Editor/            сборка из командной строки
Assets/Scenes/App.unity   сцена: только Canvas, камера и EventSystem
Tools/BrainshTests/       53 дифф-теста против референсного интерпретатора
```

Интерфейс собирается из кода при запуске (`AppBootstrap`), поэтому сцена почти пустая.

## Управление

| Действие | Как |
|---|---|
| Ввод текста | экранная клавиатура или обычная клавиатура на ПК |
| Каретка | тап или клик по коду, двойной клик выделяет слово |
| Выделение | долгое нажатие и ведение пальцем |
| Прокрутка | перетаскивание, колесо мыши, полоса справа |
| Копировать / вставить | `Ctrl+C` / `Ctrl+V`, кнопки клавиатуры |
| Отменить / вернуть | `Ctrl+Z` / `Ctrl+Y`, кнопки `Undo` / `Redo` |
| Запуск / стоп | `Run` / `Stop` |
| Файлы, примеры, настройки | `Files`, `Menu` |
| Выход | `Exit` |
